# Moduli in Flanders

Website of the workshop "Moduli in Flanders" (Antwerp, 24–25 March 2027), held on the occasion of the honorary doctorate of Rahul Pandharipande. It is a static page served by GitHub Pages from the `main` branch.

## Editing

All text is in `index.html`. Each block starts with a comment in capitals (`SPEAKERS`, `PROGRAMME`, `PRACTICAL INFORMATION`, …). To change something, open `index.html` on github.com, click the pencil icon, edit the text between the tags and commit; the site updates a minute or two later.

- A talk: in the `PROGRAMME` block replace `Lecture 3 <span class="tba">To be announced</span>` by, for example, `Speaker Name <span class="tba">Title of the talk</span>`.
- Venue and registration: the `PRACTICAL INFORMATION` block.
- Colours and fonts: the top of `style.css`.

## Files

- `index.html`, `style.css`: the page.
- `assets/`: images and sponsor logos.
- `posters/`: the two posters as PDF, with previews.
- `fonts/`: the typefaces, all under the SIL Open Font License (`fonts/OFL.txt`).
